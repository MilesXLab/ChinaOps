# Print Pack

**Plain English:** Print before your flight. Prefer the **A4 duplex** sheet (one paper, two sides) if your printer supports double-sided printing. Use the **bilingual** page if you want English + 简体中文 on a single side.

Printer tips:

- **A4 duplex:** “Flip on long edge” / 长边翻转  
- **PDF:** Save PDF first if hotel printers are awkward  
- Handwrite hotel 中文 address on the blank lines

## What is included

### Emergency
- Police **110** · Ambulance **120** · Fire **119** · NIA **12367**
- Blank lines for hotel / embassy
- Dead-phone plan + crisis phrases

### Phrases
- Payment, taxi, hotel, food, allergy, nursing, metro, lost items
- Format: **中文 / pinyin / English** (bilingual pack drops pinyin to fit one page)
