## Checklist (printable)

1. [ ] Power bank in **carry-on** (CCC+QR if domestic flight)  
2. [ ] eSIM/SIM + VPN **tested at home**  
3. [ ] Alipay + WeChat cards bound; bank knows you travel to China  
4. [ ] Cash buffer plan (~500 RMB)  
5. [ ] Hotel address screenshot in **汉字**  
6. [ ] Passport + booking screenshots offline  
7. [ ] Offline maps + dictionary  
8. [ ] One hospital saved in maps  
9. [ ] **Print pack** printed or PDF saved  
10. [ ] Digital arrival card ready (or paper fallback)  
11. [ ] If with kids: formula / meds / allergy card  
12. [ ] Peak holiday? HSR / hotels booked
